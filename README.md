# 🔐 Secure Login System

A simple and secure login and registration system built with **Python Flask**, **SQLite**, **HTML**, and **CSS**.

## 🚀 Features

- 👤 User registration
- 🔑 Secure user login
- 🔒 Password hashing
- 🗄️ SQLite database
- 🛡️ Session-based authentication
- 📊 Protected user dashboard
- 🚪 Logout functionality
- 🎨 Simple and responsive UI

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- Werkzeug
- Jinja2
